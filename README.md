# What the Elevator Would Say

make.fun bounty entry. A Node program that writes the funniest one line a talking elevator could say to `entry.txt`.

Entry (113 characters):

> I have carried 40,000 people and not one of them has ever said thank you. The stairs get a thank you. The stairs.

Run with `node main.ts`. The entry is written to `(MAKEFUN_OUTPUT_DIR ?? "/output")/entry.txt`.
